01 · Upload

上传截图

只识别澳洲号码：手机 04XX XXX XXX、座机 0X XXXX XXXX、1300 / 1800。通话记录截图可以直接用，日期和地名会被忽略。

02 · Name

命名

First name 名
Last name 姓

打开「连续数字」，名字后面会依次加上 1、2、3…，右边的框是起始编号。关掉就是所有人用同一个名字。

03 · Export

导出 VCF

还没有号码。

你现在是在 App 内置的浏览器里，这里一般无法导入联系人。请点右上角「…」选「在 Safari 中打开」，或复制网址到 Safari：
iPhone 批量导入
  1. 用 Safari 打开本页，点「导入通讯录」，在弹出的联系人预览里点「添加全部 N 个联系人」。
  2. 如果只看到一个联系人或没有反应：点「分享」→ 发给自己（信息、邮件或隔空投送），再在信息/邮件里点开这个附件 →「添加全部 N 个联系人」。
  3. 也可以在电脑上打开 icloud.com/contacts，点「+」→「导入联系人」选这个 .vcf，几秒后同步到手机。
